# ELDORA – חנות תכשיטים מקוונת

פרויקט קורס: חנות מקוונת ב-HTML, CSS, JavaScript ו-Bootstrap, בלי שרת. כל הנתונים (שם המשתמש, הסל, המלאי וההזמנות) נשמרים בדפדפן ב-localStorage.

## איך פותחים את האתר

פותחים את הקובץ `index.html` בדפדפן (לחיצה כפולה). לא צריך שרת ולא צריך חיבור לאינטרנט: Bootstrap, האייקונים והגופנים שמורים בתיקייה `vendor`. מומלץ להשתמש ב-Chrome או ב-Edge.

## חברות הקבוצה

| שם | חלק בפרויקט |
| --- | --- |
| טלי גלזמן | עמוד התשלום (`checkout.html`) |
| עדי שטיין | עמוד הכניסה ושם המשתמש (`index.html`, `user.js`) |
| נועה משולם | רשימת המוצרים והתמונות (`products.js`) |
| שולמית דרויש | עמוד החנות והוספה לסל (`shop.html`) |
| ברכי אנגל | עמוד הסל (`cart.html`) |
| אלינור אגד | עיצוב, חיפוש, שפות, עמוד ההזמנות וחיבור כל העמודים |

## העמודים

| עמוד | מה יש בו |
| --- | --- |
| `index.html` | כניסה: בחירת שפה (עברית / English) והכנסת שם מלא, עם בדיקת תקינות |
| `shop.html` | החנות: 12 תכשיטים, סינון לפי קטגוריה, חיפוש, מיון, חלון פרטי מוצר והוספה לסל |
| `cart.html` | סל הקניות: שינוי כמות, מחיקת מוצר, ריקון העגלה וסיכום מחיר |
| `checkout.html` | תשלום מדומה: פרטי משלוח ותשלום עם בדיקות תקינות, הורדת הכמויות מהמלאי והודעת הצלחה |
| `orders.html` | ההזמנות שלי: היסטוריית כל ההזמנות עם תאריך, מוצרים וסכום |

## מה האתר יודע לעשות

- **12 פריטים**, ולכל אחד: מספר סידורי (מק"ט), שם, מחיר, תמונה, תיאור, קטגוריה וכמות במלאי.
- **משלוח**: חינם מעל ₪200, ומתחת לזה ₪25. הסל מראה כמה חסר למשלוח חינם.
- **סל והזמנות נפרדים לכל משתמש**: מי שנכנסת אחרי מישהי אחרת באותו מחשב לא רואה את הסל וההזמנות שלה.
- **ניהול מלאי**: אי אפשר להוסיף לסל יותר ממה שיש. אחרי תשלום המלאי יורד ונשמר גם אחרי רענון.
- **שם המשתמש** מוצג לאורך כל האתר: בתפריט העליון, בראש עמוד החנות, בסל ובטופס התשלום.
- **הודעות למשתמש**: הודעות קופצות על כל פעולה, חלונות אישור לפני מחיקה ויציאה, וחלון הצלחה עם מספר הזמנה.
- **חיפוש, סינון ומיון** בעמוד החנות.
- **חלון פרטי מוצר** עם תמונה גדולה ובחירת כמות.
- **היסטוריית הזמנות** בעמוד נפרד.
- **שתי שפות**: עברית (מימין לשמאל) ואנגלית (משמאל לימין), עם מעבר בכל עמוד.
- **מצב כהה** ומצב בהיר.
- **מותאם לטלפון**.

## נתונים ב-localStorage

| מפתח | מה נשמר |
| --- | --- |
| `userName` | השם המלא של המשתמש |
| `cart:<שם המשתמש>` | הסל של כל משתמש בנפרד: `[{ id, quantity }]` |
| `stock` | המלאי של כל מוצר אחרי קניות |
| `orders:<שם המשתמש>` | ההזמנות של כל משתמש בנפרד |
| `lang` | השפה שנבחרה (`he` / `en`) |
| `theme` | מצב כהה / בהיר |

כדי להתחיל מחדש (למשל להחזיר את המלאי לכמות המקורית), מוחקים את המפתחות האלה בכלי המפתחים של הדפדפן.
